# Map Tile Editor

언리얼 에디터에서 **2D 격자에 클릭해서 레벨의 타일과 프랍을 배치하는** 툴입니다.
타일맵 편집기처럼 칠하면 실제 레벨 액터가 생기고 지워집니다.

> **English**: An Unreal Editor plugin that lets you paint level geometry on a 2D grid,
> like a tilemap editor. Painting a cell spawns a real actor in the level; erasing destroys it.
> Supports layers (floor / prop / actor), multi-cell footprints, rotated grids, and full editor undo.
> UI strings are in Korean.

- **엔진**: Unreal Engine 5.7 (에디터 전용 모듈)
- **의존성**: 엔진 기본 모듈만 사용합니다. 외부 라이브러리 없음
- **코드**: C++ 약 3,200줄

---

## 무엇을 하는 툴인가

레벨을 손으로 배치하다 보면 같은 규격의 바닥 타일을 수백 개 놓게 됩니다.
이 툴은 그 작업을 **2D 격자 위에 칠하는 일**로 바꿉니다.

- 격자 한 칸을 클릭하면 그 칸에 해당하는 월드 위치에 액터가 스폰됩니다
- 우클릭하면 지워집니다
- 별도의 "적용" 단계가 없습니다. 칠하는 즉시 레벨이 바뀝니다
- `Ctrl+Z`로 되돌아갑니다 (에디터 Undo 스택에 그대로 올라갑니다)

**툴은 별도 저장본을 두지 않습니다.** 레벨 자체가 원본이고, 격자는 레벨을 훑어 만든 투영입니다.
그래서 툴 밖에서 배치한 것도 격자에 나타나고, 툴이 만든 것도 평범한 액터라 아무 방법으로나 편집할 수 있습니다.

## 설치

프로젝트의 `Plugins/` 아래에 클론하고 프로젝트를 다시 생성/빌드하면 됩니다.

```
cd <YourProject>/Plugins
git clone https://github.com/Chang-Jin-Lee/UnrealMapTileEditor.git MapTileEditor
```

`.uproject`를 우클릭 → `Generate Visual Studio project files` 후 빌드합니다.

여는 법: 에디터 상단 **`Tools` → `Metropia` 섹션 → `맵 타일 편집기`**

> 메뉴 섹션 이름을 바꾸려면 `Private/MapTileEditor.cpp`의 `FindOrAddSection("Metropia", ...)` 를 고치면 됩니다.

## 빠른 시작

### 1. 팔레트 만들기 (처음 한 번만)

팔레트는 "어떤 타일을 쓸 수 있는지"를 담아두는 애셋입니다. 레벨마다 하나 만들어 두고 계속 씁니다.

1. 툴 상단의 **`새 팔레트`** 를 눌러 이름을 정해 저장합니다
2. 레벨에서 **배치하고 싶은 것을 하나 클릭**합니다 (바닥 타일, 기둥, 블루프린트 무엇이든)
3. 툴 왼쪽 아래 **`선택 액터 외형 등록`** 을 누릅니다
4. 2~3번을 반복해 쓸 것들을 채웁니다

등록할 때 **메시 · 머티리얼 전체 슬롯 · 스케일 · 충돌 프로파일**을 함께 담습니다.
스태틱 메시 액터는 `바닥` 레이어로, 그 밖의 액터(블루프린트 포함)는 `프랍` 레이어로 들어갑니다.

### 2. 격자를 레벨에 맞추기

팔레트의 격자 설정을 그 레벨의 실제 배치 규격에 맞춰야 칸이 어긋나지 않습니다.

| 설정 | 의미 |
|---|---|
| `CellSize` | 한 칸의 월드 크기(cm). 보통 바닥 메시의 한 변 길이 |
| `GridOrigin` | 격자 (0,0) 칸의 중심이 놓이는 월드 위치. 기준으로 삼을 타일 하나의 위치를 넣으면 됩니다 |
| `GridYaw` | 격자 전체의 회전(도). 아래 "회전된 격자" 참고 |

### 3. 칠하기

왼쪽 목록에서 타일을 고르고 가운데 격자를 클릭하거나 드래그합니다.

## 조작

| 입력 | 동작 |
|---|---|
| 좌클릭 / 드래그 | 칠하기 |
| 우클릭 / 드래그 | 지우기 |
| `Alt` + 좌클릭 | 스포이드 — 그 칸의 타일과 회전값을 브러시로 가져옴 |
| `R` | 브러시를 시계 방향 90도 회전 |
| 마우스 휠 | 커서 기준 확대 / 축소 |
| 가운데 버튼 드래그 | 캔버스 이동 |
| `Ctrl+Z` | 되돌리기 |

`직사각형`을 켜면 드래그한 범위가 한 번에 채워집니다. 한 스트로크가 트랜잭션 하나이므로
100칸을 드래그해도 `Ctrl+Z` 한 번에 전부 되돌아갑니다.

## 레이어 — 바닥 위에 물건 올리기

타일마다 **바닥 / 프랍 / 액터** 중 하나에 속합니다. 레이어가 다르면 **같은 칸에 함께 놓입니다.**

- 바닥을 깔고 그 위에 기둥(프랍)을 칠해도 바닥이 지워지지 않습니다
- 같은 레이어에서만 서로를 교체합니다
- 지우기와 스포이드는 **보이는 레이어 중 가장 위**(액터 → 프랍 → 바닥)를 대상으로 합니다
- `레이어 표시`에서 특정 레이어를 끄면 그리지도, 지우지도, 집지도 않습니다

캔버스는 아래 레이어를 넓게 그려 위 레이어가 안쪽에 얹힌 것처럼 보입니다 (바닥 100% / 프랍 62% / 액터 38%).

## 점유 칸 (Footprint)

지하철이나 큰 프랍처럼 여러 칸을 차지하는 것은 `선택 타일` → `점유 칸 (가로 x 세로)`에 크기를 넣습니다.

- 액터는 점유 영역의 **중앙에 하나만** 스폰됩니다
- 캔버스에 노란 테두리로 점유 범위가 표시됩니다
- 그 범위 안 아무 칸이나 우클릭하면 배치 전체가 지워집니다
- 같은 레이어에서 범위가 겹치면 겹친 기존 배치 전체가 먼저 걷혀 나갑니다

## 회전된 격자

맵이 월드 축과 어긋나게 지어진 경우가 있습니다. 예를 들어 타일이 전부 45도 돌아가 있으면,
월드 X축 기준 간격이 `셀크기 / √2`로 나와 격자가 맞지 않습니다.

`GridYaw`에 그 각도를 넣으면 격자 축 전체가 회전합니다.

- 셀↔월드 변환, 레벨 역스캔이 모두 이 각도로 회전·역회전합니다
- **배치되는 액터도 이 각도를 기본 회전으로 물려받아** 기존 배치와 나란해집니다
- 허용 오차도 격자 축 기준으로 잽니다 (월드 축으로 재면 같은 칸의 타일이 최대 `셀크기 × 0.707`만큼 벗어난 것으로 잡혀 스캔에서 빠집니다)

각도를 찾는 방법: 기존 타일 하나의 액터 Yaw를 보거나, 타일 위치들을 여러 각도로 역회전시켜
간격이 정수배로 떨어지는 각도를 찾으면 됩니다.

## 레벨 스캔

`현재 레벨 새로고침`은 레벨을 훑어 격자를 다시 만듭니다. 두 부류를 읽습니다.

1. **툴이 배치한 액터** — `MapTile` 태그로 식별하고, `MapTileId=<GUID>` 태그로 어느 팔레트 타일인지 복원합니다
2. **원래 있던 타일** — 아래 세 조건을 모두 통과하는 스태틱 메시 액터

| 조건 | 설정 |
|---|---|
| 메시 이름에 지정한 조각이 포함 | `ScanMeshNameFilters` |
| `GridOrigin.Z` 로부터 Z 허용 범위 안 | `ScanHeightTolerance` |
| 격자 축 기준 오차가 허용치 안 | `ScanSnapTolerance` |

2번으로 읽은 것은 캔버스에 어둡게 그려져 툴이 놓은 것과 구분됩니다.

> **이 두 값은 함께 조정해야 합니다.** 오차만 넓히면 격자와 무관한 장식물까지 바닥으로 잡혀
> 덮어 칠할 때 함께 지워집니다. 필터만 걸고 오차를 좁히면 손으로 배치해 조금씩 어긋난
> 기존 타일을 놓칩니다.
> 손배치 맵의 권장 조합은 **오차 = 셀 크기의 절반 + 메시 이름 필터**입니다.

## 배치되는 액터는 어떻게 만들어지는가

칠하기는 **기존 액터를 지우고 새 액터를 스폰**합니다. 머티리얼만 바꾸는 것이 아닙니다.

팔레트 정의에서 오는 것:

| 항목 | 비고 |
|---|---|
| 메시 + 머티리얼 슬롯 | `ActorClass`가 지정되면 그 클래스를 대신 스폰합니다 |
| 스케일 | |
| 충돌 프로파일 | 비워두면 액터 기본값. 원본과 다른 프로파일을 쓰면 충돌 거동이 바뀝니다 |
| 위치 | 점유 영역 중심 + `PlacementOffset` |
| Yaw 회전 | `GridYaw` + 브러시 Yaw + `YawOffset` |

**아웃라이너 폴더**는 이렇게 정해집니다.

1. 이미 타일이 있던 칸을 덮어 칠하면 → **그 칸에 있던 액터의 폴더를 물려받습니다**
2. 빈 칸에 새로 놓으면 → 팔레트의 `DefaultFolderPath`

덕분에 기존 방/구역 정리가 무너지지 않고, 새로 추가한 타일은 한 폴더에 모여 찾기 쉽습니다.

팔레트 정의에 없는 것은 승계되지 않습니다. Pitch/Roll(Yaw만 적용), 라이트맵 오버라이드,
커스텀 프리미티브 데이터, 붙어 있던 자식 액터 등입니다. 원본이 이 값들에 기대고 있으면
`FMapTileDef`에 필드를 추가하고 `SpawnTileActor()`에서 적용해 주세요.

## 되돌리기

한 스트로크가 `FScopedTransaction` 하나로 묶입니다.

```cpp
const FScopedTransaction Transaction(LOCTEXT("PaintTilesTransaction", "2D 맵 타일 칠하기"));
```

액터 스폰 시 `RF_Transactional`을 주고, 삭제 전 `Modify()`를 호출한 뒤 `EditorDestroyActor`를 씁니다.
덮어 칠하기는 `파괴 + 스폰`인데 둘 다 같은 트랜잭션 안에 있어, 되돌리기 한 번에
**파괴된 액터가 되살아나고 새 액터는 사라집니다.**

그리드 모델 자체는 트랜잭션 대상이 아니므로, 위젯이 `FEditorUndoClient`를 상속해
`PostUndo` / `PostRedo`에서 레벨을 다시 읽습니다. 이게 없으면 되돌리기 후 캔버스가
이미 사라진 액터를 계속 그립니다.

## 팔레트 설정 전체

### `UMapTilePalette`

| 프로퍼티 | 기본값 | 설명 |
|---|---|---|
| `CellSize` | `800` | 한 칸의 월드 크기(cm) |
| `GridOrigin` | `(0,0,0)` | (0,0) 칸 중심의 월드 위치 |
| `GridYaw` | `0` | 격자 전체 회전(도) |
| `ScanMeshNameFilters` | 없음 | 바닥으로 인정할 메시 이름 조각. 비우면 모든 스태틱 메시가 후보 |
| `ScanHeightTolerance` | `400` | 스캔 Z 허용 범위(cm) |
| `ScanSnapTolerance` | `1` | 격자 축 기준 허용 오차(cm) |
| `DefaultFolderPath` | 없음 | 빈 칸에 새로 놓을 때의 아웃라이너 폴더 |
| `Tiles` | 없음 | `FMapTileDef` 배열 |

### `FMapTileDef`

| 프로퍼티 | 설명 |
|---|---|
| `DisplayName` | 목록에 표시할 이름 |
| `Layer` | `바닥` / `프랍` / `액터` |
| `Footprint` | 점유 칸 수 (가로 × 세로) |
| `Mesh` + `MaterialOverrides` | 스태틱 메시 배치 경로 |
| `ActorClass` | 블루프린트/네이티브 액터 배치 경로. 지정되면 `Mesh` 대신 사용 |
| `CollisionProfileName` | 비어 있으면 액터 기본값 |
| `Scale` / `PlacementOffset` / `YawOffset` | 배치 트랜스폼 |
| `PreviewColor` | 캔버스 셀 색 (텍스처를 못 찾을 때 사용) |
| `TileId` | 팔레트를 재정렬해도 레벨 배치와 연결이 끊기지 않게 하는 GUID |

## 알려진 한계

- **한 칸 · 한 레이어에 하나**입니다. 같은 레이어에 두 개를 겹쳐 놓을 수는 없습니다
- **회전은 Yaw만** 적용됩니다. 기울어진 타일은 표현하지 못합니다
- 셀 미리보기는 타일의 대표 텍스처를 찾아 그립니다. 머티리얼 파라미터 이름이 관례를
  벗어나면 엉뚱한 텍스처가 잡힐 수 있습니다. 그때는 `PreviewColor`로 대체됩니다
- 블루프린트 배치 경로에는 `CollisionProfileName`을 적용하지 않습니다.
  블루프린트가 정한 값을 존중합니다
- 모듈 타입이 `EditorNoCommandlet`이라 커맨드릿에서는 로드되지 않습니다.
  헤드리스 스크립트로 팔레트를 다루려면 `Editor`로 바꿔야 합니다

## 만든 배경

게임 프로젝트 *메트로피아: 종말식당*의 지하철 맵 작업에 쓰기 위해 만들었습니다.
다른 팀(산삼원정대)이 만든 같은 성격의 툴 시연 영상을 참고해 UI와 조작 규칙을 잡았고,
코드는 처음부터 새로 작성했습니다.

`GridYaw`, `Footprint`, 레이어, 충돌 프로파일 승계, 아웃라이너 폴더 승계는
실제 맵에 적용하면서 필요해진 것들입니다. 특히 회전 격자 지원은 대상 맵이
45도 돌아간 격자 위에 지어져 있어서 추가했습니다.
